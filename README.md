## 🌟 ฟีเจอร์หลักของระบบ (Key Features)

### 1. ระบบจัดการโปรไฟล์สัตว์เลี้ยง (Multi-Pet Profiles)
- ลงทะเบียนสัตว์เลี้ยงได้หลายตัว (สุนัข, แมว, กระต่าย, นก และอื่น ๆ)
- จัดเก็บข้อมูลพื้นฐาน: ชื่อ, สายพันธุ์, วันเกิด, เพศ, น้ำหนักเริ่มต้น, เป้าหมายแคลอรีต่อวัน และรูปภาพประจำตัว
- รองรับการเข้าดูหน้ารายละเอียดและแก้ไขข้อมูลผ่านหน้าเว็บแบบไดนามิก

### 2. บันทึกไดอารี่และน้ำหนัก (Daily Log & Weight Tracker)
- บันทึกกิจกรรมประจำวัน หรือประวัติสุขภาพย้อนหลัง
- บันทึกค่าน้ำหนักประจำวัน โดยระบบจะดึงข้อมูลย้อนหลังสูงสุด 7 บันทึกมาสร้าง **กราฟแนวโน้มน้ำหนัก (Weight Trend Chart)** แบบ SVG อัตโนมัติบนหน้าแดชบอร์ด
- จัดการข้อมูลได้ง่ายด้วยเมนู Dropdown (จุดสามจุด) เพื่อ **แก้ไข (Edit)** และ **ลบ (Delete)** บันทึกได้ทันที

### 3. ระบบติดตามโภชนาการและการกินอาหาร (Nutrition Tracker)
- บันทึกมื้ออาหารแยกตามช่วงเวลา (เช้า, กลางวัน, เย็น, ของว่าง) พร้อมระบุแคลอรี (kcal)
- คำนวณความต้องการพลังงานขั้นพื้นฐาน (RER) และพลังงานทั้งหมดต่อวัน (DER) ตามค่าน้ำหนักล่าสุดอัตโนมัติ
- แสดงแถบ **Progress Bar โภชนาการวันนี้** เทียบกับแคลอรีเป้าหมายแบบเปอร์เซ็นต์

### 4. ปฏิทินจัดการนัดหมาย (Interactive Calendar)
- แสดงภาพรวมนัดหมายรายเดือน พร้อมสัญลักษณ์ **จุดกลมสีส้ม** แจ้งเตือนในวันที่มีนัด
- เมื่อคลิกวันที่บนปฏิทิน ระบบจะทำการ **กรองรายการนัดหมายเฉพาะของวันนั้น** มาแสดงผลด้านขวาทันที
- รองรับการทำเครื่องหมายสำเร็จการนัดหมาย (Task Completion Toggle) ผ่านระบบ **Ajax** เรียลไทม์โดยไม่ต้องรีเฟรชหน้าจอ

### 5. เกร็ดความรู้อัจฉริยะ (Rotating Tips)
- ดึงข้อแนะนำการดูแลสัตว์เลี้ยงให้ตรงกับประเภทที่ผู้ใช้กำลังเปิดดู (สุนัข / แมว / กระต่าย)
- มีระบบสลับหมุนเวียนข้อแนะนำใหม่ในฐานข้อมูลโดยอัตโนมัติทุก ๆ 10 วินาที

## 🛠️ เทคโนโลยีที่ใช้พัฒนา (Tech Stack)
- **Backend Framework**: Django 4.x / Python 3.11+
- **Frontend UI & Styling**: HTML5, Vanilla CSS + Tailwind CSS (ดีไซน์สไตล์ Pastel พร้อม Micro-animations)
- **Database**: PostgreSQL (Production บน Render & Local Development บน Docker)
- **Containerization**: Docker & Docker Compose
- **CI/CD Pipeline**: GitHub Actions (CI ตรวจสอบการ Build / CD สั่ง Deploy อัตโนมัติไปยัง Render)

## 📦 วิธีการติดตั้งและรันระบบในเครื่องจำลอง (How to Run Locally)

เมื่อติดตั้ง Docker Desktop เรียบร้อยแล้ว สามารถใช้คำสั่งต่อไปนี้ในโฟลเดอร์หลักของโปรเจกต์:

```bash
# 1. สั่งรัน Container ทั้งหมดในแบบ Background (รวมทั้งเว็บและฐานข้อมูล PostgreSQL)
docker compose up -d --build

# 2. ทำการ Migrate โครงสร้างฐานข้อมูลไปยัง PostgreSQL
docker compose exec web python manage.py makemigrations
docker compose exec web python manage.py migrate

# 3. สร้างสิทธิ์ผู้ดูแลระบบ (สำหรับเข้าใช้งานผ่านหน้า /admin)
docker compose exec web python manage.py createsuperuser

# 4. เข้าใช้งานระบบผ่านเบราว์เซอร์
URL: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)
